GnomeMeteo

Elegant, lightweight weather indicator and forecast for the GNOME desktop. Native Libadwaita styling, multi-provider accuracy, and zero API keys.

GitHub Repository Latest Release (.zip)
🚀 One-Liner Install & Update (No sudo)
🔒 SHA-256 + Sigstore SLSA verification
$ curl -fsSL https://raw.githubusercontent.com/OleksiyM/GnomeMeteo/main/install.sh | bash
Live Weather & 7-Day Forecast Card
Clean Single-Page Libadwaita Preferences

Designed for the Modern GNOME Desktop

🌡️
Segmented Metric Switcher
Switch seamlessly between Temperature, Precipitation probability, and Wind speed across both the 24-hour strip and 7-day forecast rows.
🌅
Solar, Lunar & Barometric Details
At-a-glance 2×2 grid displaying Sunrise/Sunset times with computed Daylight duration, astronomical Moon Phase, Dew Point, and Barometric Pressure level.
🌍
Keyless Multi-Provider Engine
Choose between Open-Meteo (with ECMWF IFS, DWD ICON, NOAA GFS models), MET Norway, or US NOAA NWS. Zero accounts, zero API keys, zero telemetry.
📊
7-Day Gradient Visualizer
Native St horizontal temperature range bars showing weekly minimum and maximum temperature spans at a glance.
📍
Smart Location Discovery
Automatic detection via system GeoClue or public IP fallback, plus instant localized city search with coordinate subtitles in Libadwaita preferences.
🌐
Full Localization & Units
Complete Ukrainian, English, and Russian translations. Instant switching between Metric (°C, km/h, mmHg) and Imperial (°F, mph, inHg) systems.

🛡️ Verifiable Supply-Chain Security

Every GnomeMeteo release is built reproducibly on GitHub Actions, verified with SHA256SUMS, and cryptographically attested with Sigstore SLSA v1 provenance. The installer automatically verifies checksums and provenance via gh attestation verify when GitHub CLI is installed (or enforce strictly with --require-provenance).
