GnomeMeteo

Elegant, lightweight weather indicator and forecast for the GNOME desktop. Fast, keyless multi-provider support with native Libadwaita styling.

GitHub Repository Releases (.zip)
🚀 One-Liner Install (No git clone, no sudo)
$ curl -fsSL https://raw.githubusercontent.com/OleksiyM/GnomeMeteo/main/install.sh | bash
Live Weather & Forecast Popup
Native Libadwaita Preferences
✨
Top Panel Indicator
Live temperature and weather conditions right in the GNOME status area. Toggle icon or temperature display dynamically without restarting.
⏱️
Hourly Forecast & Metrics
Switch seamlessly between Temperature, Precipitation chance, and Wind speed metrics with dedicated controls and pagination.
🗓️
7-Day Gradient Visualizer
Daily forecast overview with visual temperature range bars showing weekly minimum and maximum temperatures at a glance.
⚙️
Libadwaita Preferences
Single-page preferences window with automatic location discovery, multi-provider selection (Open-Meteo, MET Norway, NOAA), and full Ukrainian, English, and Russian localization.
