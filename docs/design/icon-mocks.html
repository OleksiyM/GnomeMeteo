5 · Rules if this ports to the app

  • One grid: every mark lives on the 24-unit box; the cloud is a single shared path, precip marks hang from a common baseline.
  • Severity by shade: cloud gradients step down partly → overcast → rain → storm, so a week strip scans before it reads.
  • Borrowed tokens: sun/bolt amber and rain blue are the chart series colours (#f5a524, #57a8ff) — icons and chart speak once.
  • Night is a language, not a filter: crescent replaces the disc; clouds drop one shade step; precip colour stays.
  • Port path: redraw these paths in glyph.js as Cairo vector ops (static, cached raster) — the animated sky stays the painter's job, icons stay crisp and cheap.
